# SpaceBaddie Avatar Studio

🚀 **Interactive Avatar Creation Platform**

A cutting-edge web application for creating and customizing gaming avatars with real-time effects, AI-powered suggestions, and professional rendering capabilities.

## ✨ Features

- 🎮 **Interactive Camera Controls** - Drag joystick to orbit avatar in real-time
- ⚡ **Real-Time Visual Effects** - Brightness, contrast, saturation, hue adjustments
- 📷 **Professional Lens Modes** - Gaming, Cinematic, Anime, Vintage, Cyberpunk, Portrait
- 🤖 **AI-Powered Suggestions** - Smart camera positioning and effect recommendations
- 🎬 **Video Recording** - Capture avatar animations with effects applied
- 📸 **Screenshot Capture** - Export high-quality PNG images
- 🌐 **Space-Themed UI** - Cyberpunk aesthetic with neon glows and holographic effects

## 🛠️ Tech Stack

- **Framework:** Next.js 14
- **Styling:** Tailwind CSS
- **Language:** TypeScript
- **Rendering:** HTML5 Canvas
- **Deployment:** Vercel (optimized)

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

## 🎮 Usage

1. **Camera Control** - Drag the blue joystick to orbit around the avatar
2. **Zoom** - Use the zoom slider to get closer or further away
3. **Effects** - Adjust brightness, contrast, saturation, and hue in real-time
4. **Lens Modes** - Switch between different visual presets for different content types
5. **Capture** - Take screenshots or record video with all effects applied
